# SINYA USEDPC Dashboard — 8.6 Pro

二手 PC 回收品售價試算儀表板（純前端，部署於 GitHub Pages）。

## 8.6 重點
- **修正 v8.5 載入即當機**：v8.5 的 `index.html` 少了篩選／批次按鈕，程式一載入就停住，清單、月係數、加入清單等功能全部失效。
- **自動存檔**：所有變更自動存在瀏覽器（localStorage），重新整理不會遺失；另可「下載備份（JSON）」與「從備份還原」。
- **Excel／CSV 匯入匯出**：匯出含計算結果與「全域參數」工作表；提供匯入範本；匯入時依標題辨識欄位並列出需確認的項目。
- **篩選與批次**：分類、關鍵字、庫存天數 ≥、只看有維修、只看有警示；可批次改毛利率、市價調整％、分類、清除月係數覆寫、刪除。
- **刪除與批次操作都可「復原」**（畫面下方提示列）。

## 定價規則

### 計算順序
毛利 → 逾期階梯 → 月係數 → 最低毛利底線 → 市價下限 → 取整（不破底線）→ 尾數（往下、不破底線）→ **市價上限**

- 初步售價 = 成本 × (1 + 毛利率)。注意這裡的「毛利率」是**成本加成率**：填 0.20 時，實際毛利 ÷ 售價 = 16.7%。
- 逾期階梯：依**回收日**算庫存天數，套用「符合的最大門檻」（不累加）。
- 市價上限 = 市場價 × (1 + 市價調整％)；市價下限 = 市價上限 × (1 + 不得低於市場價 X％)。
- 若市價上限低於底線，以**市價上限**為準，並在該列顯示 ⚠。

### 月序（8.6 定案）
- **滿 N 個曆法月 = 第 N 月**。例：8/4 購買，9/4 起為第 1 月、10/4 起為第 2 月。
- **未滿 1 個月不套係數**（係數 1.00）。
- 滿 18 個月以上固定用第 18 月。
- 月底日自動對齊：1/31 購買，2/28 即算滿 1 個月。
- 基準日依「係數月序基準」（購買日／回收日）；選購買日但購買日空白時，改用回收日。

### 尾數（8.6 定案）
- **往下取**：11,450 → 尾數9 為 11,449、尾數99 為 11,399。
- **不破底線**：往下取會低於最低毛利或市價下限時，改取底線以上最近的尾數價（例：底線 11,000 → 11,009）。
- 套用市價上限後，價格也會整理成上限以下的尾數價（例：上限 12,600 → 12,599）。

### 按月自動生成階梯
- 每 30 天一階，**逐月遞增**：線性累加（-5%、-10%、-15%…）或複利（×0.95、×0.95²…）。
- 降幅上限 -95%。

## 欄位合理性與安全性
- 數值欄位允許留空；市價調整％空白時用全域預設。
- 四捨五入單位最小 1；最低毛利率底線不允許負值。
- 月係數空白、非數字或 ≤ 0 視為 1.00；單品覆寫不足 18 個會以最後一個補齊。
- 每列自動檢查並以 ⚠ 標示：成本未填、毛利率為負或 ≥ 100%、回收日空白或在未來、購買日在未來或晚於回收日、市價上限低於底線。
- 診斷模式在每列下方顯示完整計算步驟，不會改動資料。

## Excel 匯入格式
第一列為標題，順序不拘（可有標題列前的說明列）：

| 欄位 | 說明 |
|---|---|
| 名稱 | 文字 |
| 分類 | NB／DT／MON／DIY／OTH，或 筆電、桌機、螢幕、零組件、其他 |
| 購買日、回收日 | 2025-08-04、2025/8/4、民國 114/8/4、20250804 或 Excel 日期 |
| 成本、市場價 | 數字，可含千分位或 NT$ |
| 毛利率、市價調整％ | 0.2 或 20% |
| 維修 | 是／有／Y／1 |
| 維修備註 | 文字 |
| 月係數覆寫 | 以逗號或空白分隔 |

「最終售價」「毛利額」等計算欄位匯入時略過，一律重新計算。勾選「一併匯入全域參數」會讀取「全域參數」工作表。

## 資料保存提醒
自動存檔只存在**這台電腦的這個瀏覽器**；換電腦、換瀏覽器或清除瀏覽資料前，請先「下載備份（JSON）」。

## 部署
將 `index.html`、`script.js`、`style.css` 放在 GitHub Pages 根目錄即可。Excel 功能使用 SheetJS（官方 CDN 0.20.3，載入失敗時改用 jsDelivr 0.18.5），需連網；CSV 匯入匯出不需要。
